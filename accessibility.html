Accessibility and checks

This project aims toward WCAG 2.2 Level AA. That is a target, not a claim that every requirement has been met. It has not had a formal Section 508 review.

What is built in

Named controls, a skip link, visible keyboard focus, text labels alongside color, responsive layouts, reduced motion support, and a native request dialog. Export help opens on hover or keyboard focus and can be dismissed with Escape. An expandable guide explains filters, metrics, and keyboard controls. The charts include text values, and the completion chart also has a data table.

What was checked

The project notes record calculation tests, browser interactions, selected color contrast pairs, and layout checks. Each check is tied to what was actually tested. Read the check record.

What still needs testing

Screen reader output, operating system high contrast behavior, text spacing changes, and broader browser coverage still need a dedicated review. A guideline review does not replace testing with people who use assistive technology.

Report a problem

Contact David on LinkedIn or open a GitHub issue. Include the page, what you were trying to do, and the browser or assistive technology you used. Please do not include work or customer data.
