How to read this dashboard

Team, due date, and search change the summary, charts, and request list. Status buttons change only the list.

Overdue means an unfinished request was due before November 11, 2026. Upcoming date ranges leave overdue work out. Completed on time compares completion dates with due dates, using only completed requests in this view.

Use Tab to move through controls, Enter or Space to activate buttons, and arrow keys in selection lists. Open a request for its context and next step. Escape closes request details and returns you to the list.

Select a summary card to see its requests. Team, date, and search stay applied.
